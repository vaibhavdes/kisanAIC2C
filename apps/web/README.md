# KISANAI web app (`apps/web`)

React + TypeScript app built with Vite. Works on phones and in five languages (English, Hindi, Marathi, Telugu, Kannada).

Screens: home, add farm, weather, soil and fertilizer, crop advice, field plan (satellite, Gemini plan, chat), plant doctor and expert review. Technical values keep their numbers and also get a plain-language explanation, an (i) button and a Listen button.

```bash
npm run dev        # dev server, proxies /api to the backend
npm run typecheck
npm run build      # output in dist/
```
